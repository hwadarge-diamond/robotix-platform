1. Optical Quadrature Encoder Interrupt Service Routine (ISR)

HARDWARE TIMER & INTERRUPTS

Polling an encoder in the main loop() drops pulses at high motor RPM. This template utilizes pin change interrupts (attachInterrupt) on Channel A to decode directional Gray code at hardware speed.

encoder_motor_control.ino (C++) 
// ROBOTIX Embedded Motor Driver & Quadrature Encoder ISR
#define PIN_ENCODER_A 2   // Hardware Interrupt Pin INT0
#define PIN_ENCODER_B 3   // Direction verification pin
#define PIN_PWM_MOTOR 9   // Timer1 16-bit PWM output
#define PIN_DIR_1     7   // H-Bridge Direction Input 1
#define PIN_DIR_2     8   // H-Bridge Direction Input 2

volatile long encoderTicks = 0; // Volatile for safe ISR memory access
unsigned long lastTime = 0;
double currentRPM = 0.0;
const int TICKS_PER_REV = 1024; // 1024 CPR Optical Disc

void IRAM_ATTR onEncoderPulseA() {
  // Read Channel B to determine rotation direction
  bool dir = digitalRead(PIN_ENCODER_B);
  if (dir == HIGH) {
    encoderTicks++;
  } else {
    encoderTicks--;
  }
}

void setup() {
  Serial.begin(115200);
  pinMode(PIN_ENCODER_A, INPUT_PULLUP);
  pinMode(PIN_ENCODER_B, INPUT_PULLUP);
  pinMode(PIN_PWM_MOTOR, OUTPUT);
  pinMode(PIN_DIR_1, OUTPUT);
  pinMode(PIN_DIR_2, OUTPUT);

  // Attach interrupt on Rising Edge of Channel A
  attachInterrupt(digitalPinToInterrupt(PIN_ENCODER_A), onEncoderPulseA, RISING);

  // Configure Motor forward at 65% PWM duty cycle
  digitalWrite(PIN_DIR_1, HIGH);
  digitalWrite(PIN_DIR_2, LOW);
  analogWrite(PIN_PWM_MOTOR, 166); // 166/255 = 65% PWM
}

void loop() {
  unsigned long now = millis();
  if (now - lastTime >= 100) { // 10 Hz telemetry loop
    noInterrupts(); // Atomic read to prevent race conditions
    long ticks = encoderTicks;
    interrupts();

    currentRPM = ((double)(ticks) / TICKS_PER_REV) * 600.0;
    Serial.print("Encoder Ticks: "); Serial.print(ticks);
    Serial.print(" | Actuator Velocity: "); Serial.print(currentRPM); Serial.println(" RPM");
    lastTime = now;
  }
}

2. Discrete PID Controller with Anti-Windup Clamping

DISCRETE TIME DOMAIN

Standard textbook PID controllers suffer from integrator windup when motor actuators saturate at max voltage ($\pm 12\,\text{V}$). This robust implementation includes integrator clamping and low-pass filtered derivative action.

discrete_pid.py (Python 3) 
import time
import math

class DiscretePID:
    """Industrial Discrete-Time PID Controller with Anti-Windup Protection."""
    def __init__(self, kp: float, ki: float, kd: float, sample_time: float = 0.01,
                 out_min: float = -12.0, out_max: float = 12.0):
        self.kp = kp
        self.ki = ki
        self.kd = kd
        self.dt = sample_time
        self.out_min = out_min
        self.out_max = out_max

        self.integral = 0.0
        self.prev_error = 0.0
        self.prev_measurement = 0.0

    def compute(self, setpoint: float, measurement: float) -> float:
        error = setpoint - measurement
        
        # 1. Proportional Term
        p_term = self.kp * error

        # 2. Integral Term with Anti-Windup Clamping
        self.integral += error * self.dt
        i_term = self.ki * self.integral

        # 3. Derivative Term on Measurement (eliminates setpoint step kicks)
        d_error = (measurement - self.prev_measurement) / self.dt
        d_term = -self.kd * d_error

        # Raw control effort before actuator saturation
        output_raw = p_term + i_term + d_term

        # Actuator Saturation Clamping (e.g. ±12V H-bridge PWM limit)
        output_clamped = max(self.out_min, min(output_raw, self.out_max))

        # Anti-Windup Clamping: revert integration if saturated in same direction
        if (output_raw != output_clamped) and ((error * output_raw) > 0):
            self.integral -= error * self.dt # Prevent runaway windup

        self.prev_error = error
        self.prev_measurement = measurement
        return output_clamped

# Example Execution Simulation
if __name__ == '__main__':
    pid = DiscretePID(kp=2.5, ki=0.8, kd=0.15, sample_time=0.01)
    target_pos = 90.0 # Target joint angle in degrees
    current_pos = 0.0

    print("Time(s) | Target(°) | Current(°) | Motor Output(V)")
    for step in range(50):
        voltage = pid.compute(setpoint=target_pos, measurement=current_pos)
        current_pos += voltage * 0.18 # Simple first-order plant response
        print(f"{step*0.01:6.2f} | {target_pos:9.1f} | {current_pos:10.2f} | {voltage:12.2f} V")

3. ROS 2 Mobile Robot Velocity Publisher & LaserScan Safety

RCLPY // ROS 2 HUMBLE

Autonomous mobile platforms (AMRs) run asynchronous ROS 2 nodes. This node subscribes to 2D LiDAR ranges (/scan) and publishes velocity commands (geometry_msgs/Twist) to /cmd_vel with active collision braking.

autonomous_driver_node.py (ROS 2 Python) 
#!/usr/bin/env python3
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist
from sensor_msgs.msg import LaserScan

class AutonomousAMRDriver(Node):
    """ROS 2 Node for AMR navigation and laser-based reactive collision avoidance."""
    def __init__(self):
        super().__init__('amr_autonomous_driver')
        
        # Publisher to robot differential motor base
        self.cmd_vel_pub = self.create_publisher(Twist, '/cmd_vel', 10)
        
        # Subscriber to 360-degree LiDAR scanner
        self.scan_sub = self.create_subscription(
            LaserScan, '/scan', self.scan_callback, 10
        )
        
        # 20 Hz control loop timer
        self.timer = self.create_timer(0.05, self.control_loop)
        
        self.min_forward_distance = 10.0 # meters
        self.emergency_stop_threshold = 0.45 # meters

    def scan_callback(self, msg: LaserScan):
        # Inspect front 30-degree cone (center ± 15 rays)
        center_idx = len(msg.ranges) // 2
        front_slice = msg.ranges[center_idx - 15 : center_idx + 15]
        
        # Filter valid non-zero finite ranges
        valid_ranges = [r for r in front_slice if msg.range_min < r < msg.range_max]
        if valid_ranges:
            self.min_forward_distance = min(valid_ranges)

    def control_loop(self):
        cmd = Twist()
        if self.min_forward_distance < self.emergency_stop_threshold:
            # Obstacle detected in hazard safety zone: rotate in-place
            cmd.linear.x = 0.0
            cmd.angular.z = 0.75 # rad/s counter-clockwise
            self.get_logger().warn(f'OBSTACLE at {self.min_forward_distance:.2f}m! Initiating evasive turn.')
        else:
            # Clear trajectory: cruise forward
            cmd.linear.x = 0.40 # 0.4 m/s cruise speed
            cmd.angular.z = 0.0
            
        self.cmd_vel_pub.publish(cmd)

def main(args=None):
    rclpy.init(args=args)
    node = AutonomousAMRDriver()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        node.get_logger().info('Shutting down AMR autonomous driver.')
    finally:
        node.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()

5. Engineering Glossary of Terms

Hover over any dotted term across the site or browse the definitions below for fast revision.

DOF

Degrees of Freedom

The number of independent kinematic coordinates required to uniquely locate and orient all robot links in 3D operational space (up to 6 DOF: 3 translation + 3 rotation).

ZMP

Zero Moment Point

The ground contact point where the net horizontal tipping moments generated by gravity and inertial acceleration equal zero, ensuring bipedal humanoid dynamic balance.

SLAM

Simultaneous Localization & Mapping

The computational problem of constructing an unknown environmental map while concurrently estimating the robot pose within that map using LiDAR and wheel odometry.

D-H CONVENTION

Denavit-Hartenberg Parameters

Standard 4-parameter convention ($a_i, \alpha_i, d_i, \theta_i$) attached to joint coordinate frames to compute homogeneous transformation matrices ($^{i-1}T_i$).

PID

Proportional-Integral-Derivative

Universal feedback control loop computing output commands based on present error ($P$), past accumulated error ($I$), and projected rate of change ($D$).

PWM

Pulse Width Modulation

Technique to control effective average DC voltage delivered to motor windings by rapidly switching high-power MOSFETs between ON and OFF states with variable duty cycles.

IMU

Inertial Measurement Unit

Sensor array combining 3-axis MEMS gyroscopes and 3-axis accelerometers to measure specific angular velocity and linear acceleration for dead-reckoning attitude estimation.

CAN BUS

Controller Area Network

High-reliability, noise-immune differential two-wire serial bus standard (CAN_H, CAN_L) widely used for real-time motor drive communications in automotive and industrial robots.

SINGULARITY

Kinematic Singularity

A configuration where the manipulator Jacobian matrix loses rank ($\det(J) = 0$), causing the loss of one or more degrees of freedom and requiring infinite joint velocities.
