04 // MEMORY & STATE

SEQUENTIAL CIRCUITS IN ROBOTS

Store, remember, and move with intent using clock pulses and memory registers.

MEMORY BUILDING BLOCKS

  • Flip-Flops: Keep one bit of memory (remember previous obstacle direction).
  • Counters: Track wheel rotations for precision odometry.
  • Registers: Hold multi-bit steering and velocity commands.
  • Finite State Machine (FSM): Evaluates present state + inputs to decide the next action.

ROBOT FSM STATE ENGINE

STATE 0: FORWARD

Motors synchronized, path clear

STATE 1: SENSE OBSTACLE

IDLE
