# 🤖 ROBOTIX ACADEMY // Light Edition

> An intuitive, multi-page educational platform dedicated to robotics, kinematics, sensors, actuators, and digital electronics — featuring an elegant cream light aesthetic and real-time 3D interactive structures.

---

## 🌟 What's New in this Multi-Page Edition

- **Multi-Page Architecture**: Replaced the previous monolithic single-page with clean, dedicated chapters. Each topic has its own page for maximum clarity, readability, and convenience:
  - 🏠 **Home & Overview**: [`index.html`](./index.html)
  - 🦾 **Robot Anatomy (3D Model)**: [`components.html`](./components.html)
  - 🤖 **Robot Taxonomies & Types**: [`types.html`](./types.html)
  - ⚡ **Interactive Simulators Lab**: [`simulators.html`](./simulators.html)
  - 🔌 **Digital Electronics & PWM**: [`electronics.html`](./electronics.html)
  - 🌍 **Real-World Applications**: [`applications.html`](./applications.html)
  - 🎯 **Knowledge Assessment Quiz**: [`quiz.html`](./quiz.html)
- **Cream Light Design System**: Warm cream porcelain (`#faf7f2`), crisp white cards, brushed titanium slate (`#1e293b`), and champagne amber accents (`#c27803`).
- **Interactive 3D Robotic Structures**:
  - Full procedural 6-DOF ceramic & titanium robotic arm on the home hero.
  - Interactive 3D robot subsystem explorer with clickable components.
- **Zero Dependencies**: Pure HTML5, CSS3, and JavaScript with CDN-loaded Three.js and Canvas Confetti.

## 🚀 Live Demo & How to Run in VS Code

### Option 1: VS Code Live Server
1. In VS Code, right-click [`index.html`](./index.html).
2. Click **"Open with Live Server"** (or press `Alt + L, Alt + O`).
3. Your browser will open at `http://127.0.0.1:5500/index.html`.

### Option 2: Instant Python HTTP Server
```powershell
python -m http.server 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
